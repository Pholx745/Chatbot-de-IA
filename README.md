# 🕸️🌸 PROYECTO GWEN: EN DESARROLLO 🎸🕷️

> *Este archivo reúne todo lo usado por el equipo: cursos, herramientas y asistentes de IA. Pensado para vivir en la raíz del repositorio.*

## Aprender Python

- [Curso de Python desde cero (MoureDev, YouTube)](https://www.youtube.com/watch?v=nKPbfIU442g) — curso completo en video, +8 horas.
- [Practica Python creando 6 proyectos (freeCodeCamp Español)](https://www.freecodecamp.org/espanol/news/practica-python-creando-6-proyectos-curso-gratis-paso-a-paso/) — aprender haciendo.
- [Python en Exercism](https://exercism.org/tracks/python/exercises) — 146 ejercicios con mentoría humana real, gratis.

## Git y GitHub

- [GitHub Flow (oficial)](https://docs.github.com/en/get-started/quickstart/github-flow) — el flujo de ramas que usa el equipo.
- [Hola mundo — guía oficial interactiva de GitHub](https://docs.github.com/es/get-started/start-your-journey/hello-world) — ramas, commits y pull requests sin necesitar saber programar.
- [Estrategia de ramificación de Git (DataCamp)](https://www.datacamp.com/es/tutorial/git-branching-strategy-guide) — compara GitHub Flow vs GitFlow.
- [gitignore.io / toptal](https://www.toptal.com/developers/gitignore) — genera un `.gitignore` correcto por lenguaje/framework.
- [GitHub Student Developer Pack](https://education.github.com/pack) — con correo de universidad/instituto: GitHub Copilot gratis, créditos de hosting (DigitalOcean, Azure), y más de 80 herramientas gratis. **Vale la pena que los tres lo tramiten.**

## Asistentes de IA que pueden usar (y para qué sirve cada uno)

| IA | Enlace | Mejor para |
|---|---|---|
| **Claude** | [claude.ai](https://claude.ai) | Explicaciones detalladas de código paso a paso, mantener contexto largo de todo el proyecto, redactar documentos. |
| **ChatGPT** | [chatgpt.com](https://chatgpt.com) | Uso general, brainstorming, muy usado como referencia porque hay muchísimos tutoriales que lo mencionan directamente. |
| **Gemini** | [gemini.google.com](https://gemini.google.com) | Integrado con herramientas de Google (Docs, Drive) si organizan documentación ahí. |
| **DeepSeek** | [chat.deepseek.com](https://chat.deepseek.com) | Buen apoyo en programación y razonamiento, gratuito. |
| **GitHub Copilot** | [github.com/features/copilot](https://github.com/features/copilot) | Autocompletado dentro del editor de código mientras escriben — gratis para ustedes vía el Student Developer Pack de arriba. |
| **Perplexity** | [perplexity.ai](https://www.perplexity.ai) | Buscar información actualizada con fuentes citadas (útil para investigar APIs, precios, documentación dispersa). |

**Regla del equipo:** ninguna IA reemplaza entender el código — se usan para explicar, revisar y acelerar, no para copiar-pegar sin leer.
